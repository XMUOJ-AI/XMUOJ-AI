# Vue 3 管理后台验收记录

基线：`a817bbd`（Vue 2 + Element UI）；迁移：Vue 3 + Element Plus。全部交互使用本机 Mock 管理员 `mock_admin`，未连接真实后端或执行部署。

## 已验证的行为

- 登录管理员后正确显示仪表盘、管理菜单和头像。
- 空用户名/密码显示两项必填校验且不提交；退出后访问 `/admin/problems` 回到 `/admin/login`。
- 公告、用户、网站/SMTP 设置、判题服务器、测试数据清理、题目列表/导入导出、标签治理和比赛列表均可加载 Mock 数据。
- 题目与比赛的创建、编辑及比赛内题目路由可加载表单；Simditor、代码模板和 SPJ 编辑器显示正常。
- 公告富文本通过真实键盘输入、保存，再次打开仍保留正文。
- 比赛内公告也完成编辑、保存、重新打开的闭环，列表使用原有数组响应契约。
- 修改题目的 C++ 代码模板并保存，再打开仍保留代码；CodeMirror 光标输入可用。
- SPJ 复选框取消确认后保持原值和原测试数据；确认后显示 SPJ 代码编辑区。
- 新增标签（含别名）保存成功；表格全选能够启用批量编辑按钮并打开相应弹窗。
- 标签启用开关使用 `model-value`：初始启用状态正确，关闭后刷新仍为关闭，再开启也能保存。
- 通过文件选择器上传本地 `cases.zip`，上传项进入 `is-success` 状态，用例表显示返回的数据。
- 从个人设置分别保存英语、繁体中文和简体中文，管理端标题与 Element Plus 分页按钮/每页条数同步切换；最终恢复简体中文。

## 外观恢复与检查

- 保留旧 Element 字体图标和 Font Awesome，恢复按钮、输入框、单选/多选、表单、标签、表格、分页、弹窗的原尺寸。
- 在 1440×900 下，登录卡片及两输入框/按钮的 DOM 坐标、宽高与基线一致。
- 仪表盘主容器、个人信息卡、最后登录表单、系统信息、统计卡片及标签的 DOM 坐标、宽高与基线一致。
- 题目列表列宽、表头、表格高度、面板高度及行操作按钮高度与基线一致。
- 仪表盘在 390、767、768、769、991、992、993、1199、1200、1201、1440px 的容器及两主列坐标/宽度均与基线一致。旧/新版本使用同一浏览器标签往返切换，每个点均读取 `window.innerWidth` 确认实际视口。保留 1000px 最小后台宽度；修复了 Element Plus 默认换行导致窄屏堆叠的问题。
- Vue 3 保留模板空白时，后台用户名下拉框使用显式默认插槽，避免额外文本节点导致 Element Plus 单子节点警告。

- 管理端全部 `.vue` 文件通过 Vue 3 SFC 编译检查。
- `eslint src/pages/admin` 通过。
- `vitest run tests/admin-components.test.js`：6 个测试通过，覆盖按钮单次事件、两个编辑器的外部值同步/用户输入/释放，以及 SPJ 确认状态。
- 部署脚本的 shell 语法检查通过；未运行部署脚本。
- 最终逐页检查全部 18 个后台内容路由，没有新增浏览器运行错误或警告；登录页单独检查。

## 限制

- 浏览器实测使用 Codex 内置浏览器，不能代替 Chrome/Edge/Firefox/Safari 的完整矩阵验收。
- 内置浏览器在覆盖为 1440×900 时，截图仍受实际面板宽度裁切；全页截图存在拼接异常。因此使用可见截图与 DOM 尺寸辅助对照，不宣称完成全页面的自动像素差分。
- 下载按钮可触发操作且无前端错误，但内置浏览器未向工具暴露 Blob 下载事件；不宣称已验证文件落盘。HTTP 下载权限和响应契约由 Mock 测试另行覆盖。
- 上传验证只证明前端与 Mock 回调连接正确，真实文件解析、后端权限和真实环境持久化仍需联调。

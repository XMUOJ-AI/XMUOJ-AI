# XMUOJ-AI 契约变更流程

- 版本：1.0.0
- 状态：已批准／冻结
- 更新日期：2026-08-10

冻结范围包括 `docs/` 下的说明文档、`openapi/`、`schemas/` 与黄金样例包。变更必须在同一个合并请求中：

1. 说明背景、影响模块、兼容性和回滚方案。
2. 同步更新文档、JSON Schema、OpenAPI、黄金样例和自动化测试；不允许只改其中一项。
3. 新增正例和至少一个能防止回归的反例。
4. 数据负责人审核 Schema/样例，后端负责人审核数据模型/OpenAPI/导入映射，Leader 批准不兼容变更。
5. 通过契约校验、JSONL→QDUOJ 黄金包构建、哈希、幂等、分页和权限边界测试后才能合并。

版本采用 SemVer：可选增量升级 minor，不改语义的勘误或放宽校验升级 patch，任何不兼容变更升级 major。未完成上述评审与验证的文件状态必须保持“草案”，不得标记“冻结”。

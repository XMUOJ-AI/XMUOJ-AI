## 重点边界

1. 匿名、禁用账户、APPKEY、CSRF及普通教师入口；旧API不得被全局改变。
2. null/非法字段、主键和展示编号、同键异体、重复投递、事件重放。
3. 跨申请成环、废弃与新增引用竞争、审核双版本、删除后历史。
4. ZIP路径/大小/哈希、DB事务与测试文件补偿、worker中断恢复。
5. 模型超时/错误输出、不可见题/他人提交、隐藏测试和标准答案、日志脱敏。

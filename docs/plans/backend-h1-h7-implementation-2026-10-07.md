## 交叉验证重点

1. 无权限上传者不能借相同包哈希、游标、重试或提交入口读取/操作别人的批次。
2. 随机密码交付不能绕过管理员权限，不在日志或长期文件中保留；导入失败/重复不重置账号。
3. 中文审计理由经过浏览器和代理后原样落库；非法输入不能被宽松解码替换后放行。
4. 分页范围与题目可见性一致；FTS 优化仍返回原有中文子串命中，不用性能换语义。
5. HTTPS 代理配置不接受客户端伪造协议头，不导致重定向循环；压测覆盖终态回写与重算并发。

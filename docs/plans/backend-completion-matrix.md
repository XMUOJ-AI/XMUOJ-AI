**2026-10-12 状态补充：** 首轮完整审查后的确定缺陷见[首轮整改](../reviews/backend-acceptance-2026-10-12.md)；用户随后确认比赛计分、AI 输出、依赖升级和插件复用 Session，最新验证见[第二轮整改验收](../reviews/backend-remediation-2026-10-12.md)。新功能扩展和真实环境联调暂缓，未提交或部署。以下 2026-10-07 矩阵保留其当时的实现范围与证据，不把历史通过替代最新验收。

本矩阵覆盖项目既有三个 HTTP 契约、全部 Agent 工具、完整数据模型，以及新增知识点工作契约。用户已授权持续实施，并暂缓跨团队签字/冻结；知识工作契约保持 0.9.9，学习、Agent、导入工作契约保持 1.0.0，没有代签或宣布冻结。下表登记 2026-10-07 已存在的实现与实际检查；“通过”仅限引用的测试范围，不代表所有验收项或部署验收均已完成。外部依赖未配置、测试夹具和未执行的验收均单独说明。

统计：旧 HTTP 操作 14 项（学习 6、Agent 3、导入 5）；知识点工作契约 21 项（原 16 项，加 3 项管理读取和 2 项公开分页）；另补充 Agent 会话创建/读取入口 1 项，合计 **36 个 HTTP 操作**。工具 **17 个唯一名称、18 种签名**（search_rag 按服务区分两种）。旧数据模型 25 个具名对象章节，加 3 个知识审核对象，共 **28 个模型责任项**。已有 Problem/Submission 属复用回归，其余按真实实现登记。

责任模块按领域划分，不要求为每一行新增 Django app。认证/响应共用最小基础；教师授权与学习归 learning，知识归 knowledge，导入归 import，RAG 与受控执行归 Agent/RAG。表内代码路径均相对仓库根目录；E-* 指向文末的执行记录。测试名称位于同领域 tests.py，跨领域时显式注明模块。早期 E-L 至 E-CLAUDE 保留当时证据；本轮 H1–H7 的阶段结果另列 E-H1/E-H5/E-HFULL/E-H6，最终真实链路与317项全库回归见E-H7/E-HFINAL。312项是心跳修复前的历史阶段，后续修复及conf.0005已有独立验证；数据恢复边界仍单列。

# 知识点模块前端 Agent 约束

## 生效前提

本文件必须放在实际前端 Git 仓库根目录后才生效。开始任何任务前，确认交付包已冻结为 1.0.0、README 已记录当前 40 位 commit，并且领取了一张 KP-DEV 任务卡。任一条件不满足时停止并报告。

## 权威顺序

OpenAPI 和快照 Schema 高于 PRD；PRD 高于任务卡和原型。字段、枚举、路径、状态码或页面权限冲突时停止，不自行补字段或兼容两套语义。

## 修改边界

- 只修改任务卡列出的知识模块页面目录、模块 API、必要 router、导航、SideMenu、导出和文案。
- 不修改 package.json、全局 ajax、全局路由模式、登录流程、旧题目页面和旧接口处理。
- 新增 knowledgeRequest 只解析知识模块的新包络、4xx、request_id 与无 body 的 204；不得改变旧页面请求行为。
- 不新增或升级 Vue 2、Webpack 3、Element UI、npm 包或状态管理方案。

## 页面硬约束

- 主站知识点页面只读且仅登录后可见，不出现保存、删除或审核控件。
- `/knowledge` 是列表驱动的组合探索页。首次进入只加载列表，图谱和摘要显示选择引导；点击列表项后才加载局部图谱。keyword、category、level、page、page_size 只控制列表，局部图谱只控制 depth；列表筛选变化不得清空当前知识点。
- `/knowledge/graph` 是完整图谱页，可以使用 root_code、depth、category、level，并提供键盘可用的关系表格等价视图。不得把完整图谱筛选复制到 `/knowledge` 局部图谱区。
- 管理按钮由 capabilities 展示，但后端授权始终是最终边界。
- 图谱有根时同时显示上游和下游，根距离为 0；先遍历后过滤，根始终保留；截断图不得显示悬空边。
- 审核队列只用摘要；进入审核详情后才读取完整变更或映射 payload。
- 提交人查看自己的依赖变更或题目标注申请时，详情 capabilities 不得包含 approve/reject；页面不显示审核按钮并说明不能自审。后端 403 仍需按错误码展示，不得把隐藏按钮当作授权。
- 加载、空、401、403、404、409、422、500、未保存离开和截断状态都必须有确定行为；失败时保留用户输入。

## 验证和报告

验证路由顺序、URL 筛选恢复、登录态切换、角色矩阵、键盘可用的表格等价视图、204 解析和旧页面回归。最终报告列出实际变更文件、执行过的命令与真实结果、未解决风险。

## 必须停止

需要修改全局 ajax、升级依赖、改变旧路由或旧页面语义、机器契约缺字段、缺少实际仓库 commit，或发现权限与敏感数据泄漏风险时立即停止并报告。

# XMUOJ 知识点主站原型交互规格

- 版本：0.9.9
- 适用范围：`/knowledge`、`/knowledge/graph`、`/knowledge/:code`
- 权威关系：本文件细化 PRD 页面交互，不新增接口字段。与 OpenAPI 或 PRD 冲突时停止开发并报告。

## 1 路由职责

| 路由 | 页面职责 | 允许的主要操作 |
| --- | --- | --- |
| `/knowledge` | 组合式知识点探索 | 筛选列表、选择知识点、查看局部图谱和摘要 |
| `/knowledge/graph` | 完整知识图谱 | 搜索或定位节点、筛选完整图、切换图形与关系表格 |
| `/knowledge/:code` | 知识点详情 | 查看定义、属性、前置、后继及可见关联题目 |

静态 `/knowledge/graph` 必须先于动态 `/knowledge/:code` 声明。示例知识点统一使用 `bfs_basic`；`bfs` 不是本交付包定义的种子 code。

## 2 knowledge 页面状态

### 2.1 初始状态

- 首次进入页面后请求知识点列表，恢复 URL 中的 keyword、category、level、page、page_size。
- 不自动选择第一项，不请求知识图谱。
- 图谱区显示“从下方知识点列表选择一个知识点”。
- 右侧摘要显示“选择知识点后查看简介”。

### 2.2 选择知识点

- 点击列表整行将该项设为当前知识点，不改变路由和列表 query。
- 使用列表项公开字段立即更新摘要。
- 请求 `/api/knowledge-graph?root_code={code}&depth={depth}`；不得附带 category 或 level。
- 请求期间只在图谱区域显示加载状态，列表继续可操作。
- 成功后高亮根节点，并显示 required 和 recommended 两种线型。

### 2.3 改变列表筛选

- keyword、category、level、page、page_size 变化时，只重新请求列表并更新 URL。
- 当前知识点、局部图谱和摘要保持不变；即使当前项不在新结果中也不清空。
- 点击新的列表项后才替换当前知识点并重新请求局部图谱。
- 重置只重置列表筛选与页码，不重置当前知识点。

### 2.4 局部图谱操作

- 允许修改上下游 depth、适应画布和打开完整图谱。
- 修改 depth 后，使用当前 root_code 重新请求局部图谱。
- 不提供关键词、分类、层级或状态筛选。
- 点击图中节点进入 `/knowledge/:code`。

## 3 完整图谱页面

- 节点搜索用于定位或设置 root_code，不承担知识点列表筛选。
- 允许 root_code、depth、category、level 和重置，筛选写入本页 URL query。
- 无 root_code 时 depth 不生效；界面应禁用 depth 或说明其当前无效。
- 图形视图和关系表格展示同一返回集合；键盘用户可以通过表格完成等价浏览。
- truncated=true 时显示缩小范围提示，不静默遗漏节点。

## 4 详情页面

- 展示 name、code、description、category、level、aliases、前置、后继和可见普通题。
- 关联题目只展示题号和标题，并进入现有普通题详情。
- 不展示 status、version、内部 id、创建人、审核人、待审申请或写操作。

## 5 请求和竞态

- 每个区域独立展示加载和失败状态，列表失败不得使用旧列表伪装成功，图谱失败不得清空当前摘要。
- 用户快速连续选择节点时，只允许最后一次选择的图谱响应更新界面；旧响应必须丢弃或取消。
- Session 失效后清除列表、当前知识点、图谱和摘要，再进入现有登录流程。
- 页面离开后不得让未完成请求回写已卸载组件。

## 6 原型与实现边界

原型控制信息层级、页面区域、关键动作和状态，不要求逐像素复刻。前端优先复用现有 OJ 的导航、字体、颜色、按钮、表格、分页和响应式组件；不得为复刻原型新增 UI 依赖或修改全局样式语义。
